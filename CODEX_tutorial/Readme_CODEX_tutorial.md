# Spatial Proteomics of the Human Small Intestine

### Download an install the following software on your laptop
- QuPath 0.7: https://qupath.github.io/
- R + RStudio: https://rstudio-education.github.io/hopr/starting.html

### Download the following repository on your laptop (~23GB)
- Download all files: https://zenodo.org/records/10724499
- Download the following objects from the "SpatialBiologyWorkshop_Freiburg2026" repo:
	1. "marker.csv"
	2. "min_dist_to_BM_df.RDS"
	3. "min_dist_to_epi_df.RDS"

### Read the follwoing paper:
https://www.nature.com/articles/s41586-024-07793-3#data-availability

### Hands on tutorial
1. Open the QuPath project from the repo and explore the data based on "CODEX_HandsOn_Exercise_v5.pdf"
2. Open RStudio and open the "github_duodenum.R" script
	- Download the libraries as indicated in "Load libraries"
	- Run the script chunk by chunk and try to understand what each step does
